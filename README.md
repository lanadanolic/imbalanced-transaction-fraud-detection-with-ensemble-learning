# Credit Card Fraud Detection

This project implements and compares multiple machine learning models for detecting fraudulent credit card transactions in a highly imbalanced dataset.

## Workflow

- data loading and preprocessing
- feature/target separation
- stratified train/test splitting
- feature scaling
- handling class imbalance with SMOTE
- Logistic Regression
- Random Forest
- XGBoost
- model evaluation using precision, recall, F1-score, and confusion matrices
- comparison of model performance
